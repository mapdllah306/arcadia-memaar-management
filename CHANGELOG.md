# Changelog

## V0.2.3 — Mobile Experience Upgrade
- Reworked mobile header as a compact 2-row toolbar with company and site selectors.
- Added persistent 5-item bottom navigation, wired to the existing page router and sidebar.
- Improved dashboard typography, spacing, KPI cards and panels on narrow screens.
- Introduced mobile task cards on Dashboard and task pages, and staff / attendance cards while preserving desktop tables.
- Kept all existing JavaScript modules, local demo storage key and original company logos.
- Improved modal, tap target, and screen safe-area styling for a future WebView wrapper.
- Did not implement server-side authentication, data sync or a production backend.
